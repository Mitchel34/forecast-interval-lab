# Publication scope

The public deliverable consists of original package code, behavior tests, a
hand-authored demo, method/protocol documentation and sanitized measured results.
All inputs are synthetic. No credentials, local machine paths, process identities,
private orchestration records, raw logs, wheel binaries, external datasets,
license grant or hosted CI workflow belong in this repository.

Final delivery requires separate review of every file in the exact commit and
its complete history, followed by independent remote reads of the repository
owner/public visibility, main commit, Git tree and every expected file. The
commit-bound review and remote verification receipts are retained outside this
tree to avoid a self-referential commit hash. Earlier public review records cover
their explicitly listed source hashes and observations.

The intended public repository is `Mitchel34/forecast-interval-lab`. Public
visibility does not itself grant a license. Nothing in this repository requests
a paid service, enables a hosted CI run or publishes a package to an index.
